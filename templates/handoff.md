# Handoff template

Written at the end of a session so the next one starts where this one stopped. Short on purpose: a long
handoff is a handoff nobody reads, and the next agent reads the first two lines first.

```markdown
## Where this stopped

<two or three sentences: what just happened, and what state the work is in.>

## Next steps

- <the single next action, concrete enough to start without thinking>
- <then this>

## Open questions

- <something that needs a decision, and who has it>

## Files touched

- <path> — <what changed, one clause>

## Do not repeat

- <the thing that already failed, and the reason, so the next session does not try it again>
```

The last section is the one that earns its place: a session that repeats a failed approach costs more than
a session that starts from nothing, because it looks like progress.
